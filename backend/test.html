TimeCapsule2. 타임캡슐 봉인 & 6자리 초대코드 발송

Diary (MEM-01 / 02)3. 내 일기장 (`/api/diaries` - 작성 시 적은 제목 그대로 사용, 날짜별 보기, 수정 날짜 미표기)

📔 내 일기장 목록 (날짜별 표시):
일기를 저장하거나 조회하면 이곳에 날짜별로 제목과 작성일이 표시됩니다.

Autobiography (ITV-01 / 02)4. AI 자서전 인터뷰 (`/api/interviews` - 단원 생성 및 AI 질문·답변 기록)

📖 내 자서전 단원 목차 (`interviews`):
단원을 생성하면 이곳에 목차 목록이 표시됩니다.
💬 단원별 질문·답변 기록 (`interviewQs.question_answer`):
답변을 제출하면 이곳에 AI 질문과 나의 답변 기록이 순서대로 쌓입니다.
📜 문답 기반 자동 생성된 자서전 본문 (`autobiography_text`):
답변을 제출할 때마다 AI가 문답을 엮어 한 편의 1인칭 자서전 본문을 자동으로 완성해 줍니다.

Deadman Switch (DMS-01 / 02)5. 데드맨 스위치 미접속 감지 및 유족 통합 아카이브 이메일 발송 (`/api/deadman`)

사용자가 설정한 미접속 기준 일수(inactivity_days)를 초과하면 6자리 특수문자 보안 코드(users.access_code)를 자동 생성하고 Nodemailer 이메일로 발송합니다. 유족이 열람 페이지(/capsule-view)에서 이 코드를 입력하면 고인의 일기장 + AI 자서전 + 타임캡슐 전체가 개봉되고 PDF 다운로드 및 첫 방문 14일 후 자동 삭제가 동일하게 작동합니다!

📩 데드맨 스위치 유족 이메일 발송 내역:
위 버튼을 누르거나 미접속 기간이 도래하면 유족에게 발송된 6자리 보안 코드와 이메일 미리보기 링크가 이곳에 표시됩니다.

Real Email6. 실제 이메일(Gmail / 네이버 메일) 전송 테스트 (`.env` 수정 없이 바로 발송)

• 네이버 메일 사용 시: 네이버 메일 하단 [환경설정] → [POP3/IMAP 설정] → [POP3/SMTP 사용함] 체크 후 본인 네이버 이메일과 비밀번호(2단계 인증 사용 시 애플리케이션 비밀번호)를 입력하면 실제 메일이 발송됩니다.
• 구글 Gmail 사용 시: Google 계정 관리 → [보안] → [2단계 인증] → [앱 비밀번호]에서 발급받은 16자리 비밀번호를 입력하면 실제 메일이 발송됩니다.

AWS RDS / MySQL7. AWS RDS (MySQL) 연동 전 사전 검증 & 실시간 DB 연결 테스트 (`/api/db`)

• ① 연동 전 사전 검증 (Dry-Run): AWS RDS나 MySQL을 아직 만들지 않은 상태에서도, 현재 백엔드의 5개 테이블 스키마(schema.sql), 외래키(FK) 무결성, 실제 실행될 INSERT INTO SQL 쿼리가 100% 정상인지 즉시 시뮬레이션 검증합니다.
• ② 실제 AWS RDS / MySQL 연결 테스트: AWS RDS 엔드포인트(또는 로컬 MySQL `localhost`) 정보를 입력하고 누르면 즉시 접속하여 5개 테이블 자동 생성 및 현재 데이터 동기화를 완료합니다.

🗄️ DB 스키마 및 SQL 쿼리 검증 결과:
위 [① 사전 검증 (Dry-Run 실행)] 버튼을 누르면 5개 테이블 검증 결과와 변환된 MySQL INSERT 쿼리가 표시됩니다.
